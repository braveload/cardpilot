# 카드파일럿 사이트

하루한칸과 연결되는 카드파일럿 웹 서비스입니다. CSV 또는 거래내역 화면 캡처에서 거래를 불러와 검토하고, 등록된 카드별 예상 규칙과 거래별 근거, 예상 인정 실적을 확인합니다.

- 운영 주소: https://braveload.github.io/cardpilot/
- 게시 파일: `index.html`, `cardpilot.js`, `card-rules.js`
- CSV: 브라우저 안에서 읽으며 UTF-8/EUC-KR, 최대 20MB 지원
- 캡처 이미지: 장당 10MB 이하, 최대 5장, 브라우저에서 Tesseract.js 한국어 OCR. 텍스트를 사용자가 교정한 후 거래 후보로 추가함
- 데이터 보관: 분석 내용은 브라우저 메모리에서만 처리되고 새로고침/초기화 시 사라짐. 서버로 CSV·이미지 내용은 전송하지 않음. 이미지 OCR 시 엔진과 한국어 언어 모델은 CDN에서 브라우저가 내려받음
- 공식 규칙 확인 상품 180종: BC 바로카드 6종, KB국민카드 일반 10종 및 KB BC 회원사 비씨TOP카드 1종, 현대카드 10종, 하나카드 일반 10종 및 하나 BC 회원사 10종(TnT·아시아나클럽·비씨TOP포인트 포함), 우리카드 20종(BC 국민행복·TOP포인트·다이아몬드 2종·인피니트 3종·TnT·레포츠·쉬즈 포함), IBK기업은행 BC 회원사 카드 10종, iM뱅크 BC 회원사 카드 10종, BNK부산은행 BC 회원사 카드 10종, BNK경남은행 BC 회원사 카드 10종, Sh수협은행 BC 회원사 카드 5종, 광주은행 BC 회원사 카드 9종, 삼성카드 10종, 롯데카드 10종, 신한카드 10종 및 신한 BC 회원사 2종, SC제일은행 BC 회원사 카드 7종, NH농협카드 20종(BC 회원사 발급 10종 포함). (카드별 출처·기준일·실적 기준은 `card-rules.js` 참조)
- 현대카드: M, MM, X, X Cut, Z everyday, Z family Edition2, Z work Edition2, Z play, ZERO Up(할인형·포인트형). 카드별 공식 제외 기준을 분리 적용하며, 할인 적용 확인이 필요한 거래는 확인 필요로 표시함
- 국민카드 규칙 상품: My WE:SH, WE:SH Travel, WE:SH Daily, 노리2 체크(KB Pay), Youth Club 체크, YOU Prime, ALL point, ALL, YOU Wish up, Toss KB국민카드, KB국민 비씨TOP카드(BC 회원사)
- 추가 상품 목록 154종: 은행·카드사 BC 회원사 12곳의 공식 상품 목록(최대 10종씩, 회원사별 현재 조회 가능한 수량 적용), 삼성·우리·롯데 각 10종, 하나·신한·NH농협 일반 카드 각 10종. 현재 154종 모두 공식 상품별 실적 규칙을 확인해 등록함
- 전체 상품 목록 180종 모두 공식 규칙 확인 및 등록 완료(기존 26종+추가 검증 154종). 새 상품은 공식 상세 자료에서 실적 기준·제외 항목을 확인한 뒤 순차 추가하며, 확인 전에는 거래 판정·합산 대상에 넣지 않음. 다만 최근 3개월 실적 상품은 사용자가 해당 3개월 거래내역을 분석 데이터에 포함해야 하며, 날짜 범위 자체는 자동으로 제한하지 않음
- 판정: 상품설명서 문구 및 거래 텍스트의 키워드 기반 예상이며 카드사의 업종코드, 할인 적용, 정산 결과를 대체하지 않음. 조건이 있는 거래는 확인 필요 상태로 표시
- 문의·개인정보처리방침·이용안내: 하루한칸 홈페이지 문서 연결

## GitHub Pages

`render-deploy` 브랜치를 Render 정적 사이트에 연결해 자동 배포합니다. `main` 브랜치 루트의 GitHub Pages는 별도 운영입니다. 카드별 규칙을 수정할 때는 `card-rules.js`의 공식 출처와 기준일을 함께 갱신하고, `index.html`의 예상 판정/개인정보 안내를 유지합니다.
